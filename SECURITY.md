# Security policy

Report a suspected security issue privately through GitHub's security advisory feature when it is available. Do not include access tokens, private server addresses, or unrelated personal data in logs.

Only the latest supported Minecraft 26.2 release line receives security fixes during the initial alpha period.

Official release jars are published only by the gated GitHub Actions release workflow. Verify the adjacent `.sha256` file before installing a jar. Do not trust a jar whose hash, tag commit, and `PROVENANCE.txt` do not agree.
