# Smart StepUp Camera Smoother 0.3.1

- Default Smoothness is now 150%.
- Third-person smoothing is now off by default and can still be enabled in settings.
- Reset restores these new defaults; select Done to save them.
- Existing saved settings are preserved, including when upgrading older versionless configurations.
- Camera smoothing and player movement behavior are otherwise unchanged from 0.3.0.

Available for Fabric and NeoForge on Minecraft 26.1, 26.1.1, 26.1.2, 26.2, 26.3, 1.21.11, and 1.21.1.

## Upload instructions

Upload each matching 0.3.1 JAR as a **Release**, selecting only its exact Minecraft version and loader. For versions already uploaded, add 0.3.1 as a new file and paste the changelog bullets above. Editing an old file's changelog does not update its mod code. Existing installations can select **Reset**, then **Done**, to adopt the new defaults.
