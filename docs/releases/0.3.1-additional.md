# Smart StepUp Camera Smoother 0.3.1 — Additional Minecraft ports

- Adds the remaining Minecraft/loader combinations listed by [Accessible Step](https://modrinth.com/mod/accessible-step/versions), including Minecraft 1.20.1 for Fabric and Forge.
- Uses the same 150% Smoothness and Third Person Off defaults as the existing 0.3.1 builds.
- Preserves saved settings. Reset, then Done, applies the current defaults.
- Keeps the shared camera smoothing and step detection logic; adapts camera hooks and settings screens to each Minecraft/loader API.
- This mod smooths the camera; it does not increase the player's step height.

Upload each JAR separately as **Release**, selecting only the Minecraft version and loader in its filename. Do not upload the combined ZIP as a mod file. These new ports have automated validation; manual gameplay testing of the earlier releases does not establish gameplay parity for every new target.

Target coverage was read from Modrinth's project version API on September 20, 2026; the exact added targets and dependency pins are recorded in `accessible-step-targets.json`. Matching the published version matrix is not a claim that every Accessible Step release has been tested alongside this mod.
